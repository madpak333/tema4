# DMJU hjemmeside

Implementeret i HTML5, Bootstrap 5.3.3, separat CSS3 og vanilla JavaScript.

## Sider

- `index.html` – Forside
- `om-dmju.html` – Om DMJU
- `aktiviteter.html` – Aktiviteter
- `modeljernbane.html` – Modeljernbane
- `klubber.html` – Klubsøgning med filtrering
- `kontakt.html` – Kontaktformular

Åbn `index.html` direkte i PHPStorm/browser. Bootstrap CSS/JS og Inter indlæses via CDN.

Farver og typografi følger Figma-tokens: `#1D4669`, `#ECF2FA`, `#C6D9EB`, `#CC0100`, Inter.

Figma indeholder mange billed-assets. Der er derfor anvendt udskiftelige billed-placeholderfelter i denne første implementering; de kan erstattes med lokale filer i `images/` uden at ændre layoutet. Kontaktformularen er en frontend-simulation og kræver backend/API for faktisk afsendelse.
